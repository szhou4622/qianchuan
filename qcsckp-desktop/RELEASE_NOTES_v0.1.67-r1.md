# 千川素材看盘工具 v0.1.67 正式版 r1（Windows x64）

- 改进 Google Chrome 的安装路径检测和配置继承，失效的旧路径可以回退到本机检测结果；保持现有 Chrome 授权和授权码拦截流程。
- 改进浏览器启动失败时的资源清理、配置保存提示及重试。
- 缩短压缩包内部路径，减少普通解压时遇到 Windows 长路径限制的概率；极深目录仍可能需要使用包内备用解压工具。
- 用户数据仍保存在原有的本机正式版数据目录。退出旧版后，将压缩包完整解压到新目录并运行 QCSCKP.exe。

已知情况：账户计划目录可能显示“同步未完成”，即使部分计划和素材数据已成功同步。目录完整性原因仍在排查，本版本不宣称修复此问题。千川授权的有效性由平台决定，失效时需要重新授权。

本次发布仅提供 GitHub Windows 包，不更新其他服务器的自动更新清单。

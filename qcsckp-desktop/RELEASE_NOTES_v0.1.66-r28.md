# 千川素材看盘工具 v0.1.66 正式版 r28

Windows x64。本次GitHub版本包含自r21以来的指标采集、授权隔离和大屏显示修复。

## 数据采集与指标

- 修复素材原生指标误用报表单位换算的问题；合法0保留，缺失、无效数值不再伪装成0。
- 乘方推直播使用官方素材报表，核对账户、抖音号、PC平台、视频类型和计划归属。配置与数据统一使用ALL_DATA整体数据，经营及流量指标在同一口径读取。
- 保留有展现或点击但消耗为0的素材；区分无报表记录、返回字段缺失和采集失败。接口或归属校验失败时保留上次可信数据。
- 当天完整采集成功、10分钟内且明确无当日报表记录的素材，已请求指标在页面按0展示；原始数据仍为空，不用展示零值参与投放判断。
- 修复缺报表素材导致曲线空白、低于1%的百分比解析，以及展示补零资格变化后页面缓存未刷新的问题。指标口径变化后重建比较基准，不清除历史记录。

## 账户与诊断

- 清除本机API配置或切换App ID后，解除旧账户选择、停止旧监控和未提交任务；旧请求不能恢复已清除账户。相同应用重新授权保留选择并重新核验。
- 完善提交前当前授权和乘方指标归属检查；已提交或结果未知的任务继续核验，不重复提交。
- 故障报告增加指标原始值、解析值、单位、请求范围与入库值的脱敏证据，便于区分采集、解析和显示问题。

## 简洁大屏

- 右上角恢复“数据正常 · X分钟前”等简短状态，保留采集中、延迟、异常和真实指标缺失提醒，详细说明移到悬停提示。
- 移除每条素材下方常驻的黄色口径说明；保留名称、账户计划、ID、类型和暂停标签。
- 汇总下方恢复“总统计 X 条素材”；真实缺字段时提示“指标不完整”。

## 使用与已知范围

- 当前消耗汇总仍为视频素材合计，不包含直播画面，不能直接作为计划整体消耗。乘方读取ALL_DATA整体数据，与千川页面选择“乘方期间数据”并非同一统计口径；对账时请统一日期和范围。
- 本次不增加直播画面采集，不改变追投/停投策略阈值、预算、时长或300秒采集周期。
- 更新继续复用本机激活、授权、账户、飞书、策略及历史数据；请完整解压到新目录，不要覆盖旧程序目录。
- Windows程序尚未数字签名，系统可能提示未知发布者；请核对下载来源及SHA256。
- 本次只发布GitHub Windows包，不同步自有更新服务器，不更新服务器渠道清单。

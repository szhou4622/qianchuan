## 发布门禁

1. `create_retarget`、`pause_control_task`、`adjust_control_task` 在适配器层直接抛出 `PlatformWriteBlocked`。
2. 网络层只允许 `security.py` 中明确列出的只读契约。
3. 数据库触发器拒绝真实执行状态；V1A 只能写入 `dry_run_*` 或 `archived_readonly`。
4. 本机 API 没有注册真实追投、暂停、预算或时长接口。
5. M6 未通过前不创建 V1A 完成标签、不制作安装包、不迁移用户现有运行库。

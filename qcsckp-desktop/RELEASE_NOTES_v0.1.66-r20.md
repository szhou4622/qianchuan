# v0.1.66 正式渠道 r20 — 统一 Windows 包

本包供开发者本人和学员共同使用，不区分教师版、学员版或只读专用版。软件功能和默认配置相同，个人授权、激活、账户和策略仍由各自的软件界面配置并加密保存。

## 本轮修复

- 启动：校验 Python/.NET/WebView2 关键依赖和文件哈希，识别 Windows 下载来源限制；用户同意后只处理通过校验的包内文件。启动失败只显示一次准确错误，不再接着出现误导性的页面超时。修复 GUI 跨线程生命周期及后台服务半启动回滚。
- 统一配置：打包版固定正式 API 后端和受支持的 Windows GUI/.NET 路径，忽略开发机注入的测试凭据、影子模式和隐藏环境开关。随包提供公开默认配置及软件配置指纹，不包含任何用户的秘密配置。
- 授权：App、工具账号和授权代次隔离；旧请求、旧账户缓存和旧目录不能覆盖新授权。授权失效、权限不足与真实限流分别显示；重新授权不会擅自清除真实接口限流冷却。
- 素材采集：保留素材接口单计划统计，禁止用账户汇总数据覆盖或填补缺失指标。分页逐页核对，合法大页保留；单页临时参数错误和分页漂移使用有总次数、时间和并发上限的只读复核，仍不完整时保留上次可信数据。
- 调控采集：调控状态和指标先独立校验、独立提交，不被后续素材分页失败撤销。停投仍必须满足正式计划归属、场景、官方证据、新鲜度及恢复周期安全要求。
- 后台恢复：工作线程启动确认和采集期限有界；过期批次撤销后不得写入最新数据、状态、关联或覆盖新一轮任务。系统提交内存接近上限时等待资源恢复，不无限创建线程。
- 可见性：分别显示素材、调控的成功时间和错误；显示采集阶段、页码和复核次数。故障报告区分历史过期卡、当前失败和采集中任务，保留脱敏错误帮助、分页证据和 request_id。

## 使用与保留

1. 完整解压同一份 ZIP 后运行 `QCSCKP.exe`，不要单独复制 EXE，也不要覆盖旧文件夹。
2. Windows x64 需要受支持的 .NET Framework 和 WebView2 Runtime。Python、pythonnet 和必要加载 DLL 随包；WebView2 安装引导程序随包，安装运行时可能需要联网。
3. 原正式渠道数据目录继续复用。更新不会清空激活、千川授权、飞书绑定、策略和历史流水。
4. 包内不放个人激活码、App Secret、Token、DPAPI 密文、Cookie、数据库和日志。每位使用者自行授权；软件配置一致不代表共享账户或凭据。
5. 若仍报错，从软件导出故障报告；无法进入时按弹窗路径提供 startup.log。不要发送 App Secret 或激活码明文。

本轮验收使用隔离数据库、模拟 API 和最终安装目录冒烟；不执行真实追投、停投或预算修改。Windows 程序尚未数字签名，系统可能显示未知发布者提示。本次生成本地安装包，不自动更新 GitHub 或服务器公开清单。

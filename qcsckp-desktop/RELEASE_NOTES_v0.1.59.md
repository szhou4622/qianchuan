# 千川素材看盘工具 v0.1.59

发布日期：2026-08-24

## 本次更新

- 修复直播素材追投缺少官方 `smart_bid_type` 参数导致创建失败的问题。
- 放量追投现在使用官方 `SMART_BID_CONSERVATIVE` 模式。
- 控成本追投现在使用官方 `SMART_BID_CUSTOM` 模式，并按净成交ROI或直播间成交补齐对应优化目标参数。
- 控成本追投不再错误传入 `duration`；平台按长期有效处理。
- 千川读取接口偶发返回“下游依赖服务相关错误”时，执行有限次数退避重试，不会第一次波动就直接判定失败。
- 飞书失败卡片增加官方错误码和 `request_id`，便于在巨量引擎开放平台准确排查。
- 数据大屏默认展示当前账户/计划筛选范围的素材汇总曲线；点击素材后切换为单素材曲线。

## 更新与本机配置

- 在线更新只替换安装目录中的程序文件，不删除 `%LOCALAPPDATA%\QCSCKP\official-api-v1`。
- 用户现有激活凭证、千川授权、飞书绑定、监控计划、策略、数据库和历史流水继续使用，无需重新配置。
- 公共安装包不包含开发者或其他用户的激活凭证、App Secret、Token、飞书配置及数据库。

## 说明

- 本版本不修改千川主计划，仅在官方素材调控任务接口范围内执行追投和停投。
- 真实写入仍执行账户、计划、素材、策略版本、实时指标、限频和幂等复核。

# 千川素材看盘工具 v0.1.66 正式版 r31

Windows x64，基于公开 r30，补全本地故障报告的执行证据链。

- 仍使用原来的“导出故障报告”按钮和单个 JSON 文件。第 5 版报告新增问题摘要、独立执行时间线、同账户/计划/策略/指标口径的成功对照，以及证据缺失、查询失败和容量截断说明；保留旧字段兼容。
- 新发生的追投会记录发卡候选与指标、确认选组、每组复核实际值和条件、提交意图、平台核验及飞书卡片回执。多组执行按组与执行 ID 分开；真实 0、原始缺值和展示补零不混同。
- 素材在确认时找不到，会在本地核查当前表与历史快照、投放状态及查询错误；没有官方证据不宣称素材被平台删除。停投跳过原因和采集计划/执行/资源等待证据一并导出。
- 诊断数据仅保存在本机，最多保留 7 天、2000 条及 20 MB；导出默认最近 24 小时的 20 个失败或未知执行及 5 个可比成功案例，必要时回溯 7 天。报告上限 5 MB，超限会标注省略内容。
- 导出按字段脱敏业务名称与 ID，不包含激活码、密钥、Token、Cookie、请求头或卡片正文。诊断记录失败不改变投放结果，也不触发重试。

本次是诊断能力改进，不代表已修复此前所有追投、停投或采集失败。旧版未保存的确认时数据无法还原，报告会标记为 `not_recorded`；其他电脑安装 r31 后，才能记录后续执行的新证据。策略阈值、投放接口、安全检查、提交结果均未变；不会重新创建旧追投。

退出旧程序后将 ZIP 完整解压到新目录运行，可继续使用本机原有授权、账户、策略和历史数据。Windows 程序尚未数字签名，请核对来源和 SHA256。本次只发布 GitHub Windows 包，不更新自有服务器或其正式版清单，不构建 Mac。

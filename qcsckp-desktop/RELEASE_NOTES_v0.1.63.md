# 千川素材看盘工具 v0.1.63

发布日期：2026-08-26

## 本次更新

- 修复千川账户页面的计划搜索显示问题，输入计划名称、计划ID或“计划ID 123...”时会立即隐藏不匹配的计划。
- 计划名称支持连续关键字模糊匹配；计划名称中的空格、横线和常见中文标点不会影响搜索结果。
- 搜索结果按当前账户即时过滤，分组中没有匹配计划时会自动隐藏整个空分组。
- 在首页左侧导航增加“使用教程”入口，点击后通过系统默认浏览器打开飞书教程文档。
- 使用教程入口位于“联系作者”上方，不改变现有数据大屏、账户管理、追投、停投、飞书和流水操作流程。

## 更新与本机配置

- 在线更新不删除 `%LOCALAPPDATA%\QCSCKP\official-api-v1`。
- 用户原有激活凭证、千川授权、飞书绑定、监控计划、策略、数据库和历史流水继续使用。
- 公共安装包不包含任何用户激活凭证、App Secret、Token、飞书配置或数据库。

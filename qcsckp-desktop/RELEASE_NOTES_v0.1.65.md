# 千川素材看盘工具 v0.1.65

## 停投策略触发修复

- 调控任务列表固定请求7项任务级经营指标，避免官方返回 `metrics=null`。
- 支持 `Value`、`ValueStr`、数值0、空值和缺失字段的安全解析。
- 新增“调控净成交订单数”完整落库与规则判断链路。
- 停投策略页只保留官方已验证的7项任务级指标；旧版不支持指标会明确暂停，不再静默改写。
- 停投规则周期由10分钟调整为5分钟，并记录命中数、缺失指标和跳过原因。
- 支持 `QCSCKP_REGULATION_SHADOW_MODE=1` 影子验证；命中时只记录判断，不发卡、不执行写接口。
- 官方已按 `PROCESSING` 筛选但任务行未回显状态时，仅在该热采集请求内安全继承为运行中；历史查询不猜测状态。
- `PAUSE`提交后以任务列表状态 `DISABLE`确认暂停；`OFFLINE_TIME`显示为自然到期。
- 飞书确认停投和自动停投继续先显示“已提交，正在核验”，最终以平台反查结果更新。

## 数据兼容

- SQLite仅增量增加字段，不删除已有账户、计划、规则、任务或历史流水。
- 未修改追投规则、主计划和飞书绑定配置。

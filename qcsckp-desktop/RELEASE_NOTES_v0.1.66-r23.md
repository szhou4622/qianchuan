# v0.1.66 正式版 r23 本机修复

- 修复乘方推直播素材指标全零：按官方乘方素材报表读取对应抖音号、PC平台、视频类型及乘方期间指标，完整核对该抖音号的计划归属后与当前计划素材匹配。
- 报表汇总行不作为素材；不属于当前计划的素材排除。缺少报表数据保持为空，真实0保留。读取或归属校验失败时保留上次数据和真实观察时间。
- 今日与历史补采采用同一来源；切换指标来源时建立新比较基准，避免旧零值造成虚假的消耗流速。
- 大屏及导出报告说明乘方指标范围，报告保留原始报表数值、归属证明和请求编号。
- 清除本机API配置或切换App ID后，移除当前账户选择、停止旧监控及未提交任务，保留历史数据。同一应用重新授权保留账户选择并重新核验。
- 新添加账户绑定当前授权身份；旧响应不能恢复已清除账户。完整授权目录可清理旧版留下的无权限账户。
- 提交前再次核对乘方指标归属和当前授权；清除配置与提交并发时以持久化提交边界为准，已提交或未知结果保持核验、不重复提交。

采集和停投扫描周期仍为300秒。本次没有减少完整素材目录的扫描频率。全域及推商品指标路由保持原有行为。

本机验证用途，不生成分发ZIP，不更新GitHub或服务器正式清单；原r22保留作为回滚版本。

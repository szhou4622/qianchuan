# 千川素材看盘工具 v0.1.61

发布日期：2026-08-25

## 本次更新

- 明确失败且属于可恢复错误时，单个追投最多提交3次；首次提交计为第1次。
- 第1次明确失败后等待60秒，第2次明确失败后等待120秒；第3次仍失败则终止并在飞书展示最终原因。
- 每次重试使用独立幂等执行ID，并在提交前重新检查账户、计划、素材状态、策略版本、实时指标和限频。
- 重试等待发生在账户写锁之外，不阻塞其他账户的数据采集和写任务。
- 多素材合并与多组追投按组独立执行；已经成功或正在核验的分组不会因为其他分组失败而重复提交。
- 参数错误、权限不足、素材不可投等确定性失败不自动重试，修正配置后才能重新触发。
- `51010`、网络中断等无法确认是否创建的结果不进入重试，继续使用只读对账并最终显示成功、明确失败或无法确认。
- 飞书卡片在重试等待期间显示当前尝试次数、下次尝试时间和最多3次限制。

## 更新与本机配置

- 在线更新不删除 `%LOCALAPPDATA%\QCSCKP\official-api-v1`。
- 用户原有激活凭证、千川授权、飞书绑定、监控计划、策略、数据库和历史流水继续使用。
- 公共安装包不包含任何用户激活凭证、App Secret、Token、飞书配置或数据库。

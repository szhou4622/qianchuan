# 千川素材看盘工具 v0.1.66 正式版 r29

Windows x64，基于r28，调整账户计划状态的自动刷新周期。

## 本次更新

- 账户计划目录自动刷新从每30分钟改为每5分钟；软件启动后仍立即刷新一次。
- 缩短主计划在千川后台重新开启后，被工具发现并重新核验的等待时间。刷新是只读操作，不会替用户开启、暂停或修改主计划。
- 保留恢复前的计划详情、授权及指标新鲜度核验；人工安全封锁不会因本次周期调整自动解除。
- 上一轮目录同步未结束时，刷新请求合并排队，不重复启动并发同步线程；单次失败不终止后续调度。

## 保留与限制

- 素材采集、停投规则扫描周期保持原有300秒；追投/停投阈值、预算、时长及执行方式不变。
- 5分钟指发起目录刷新的调度周期，不保证网络、限流或队列拥堵时5分钟内完成采集或恢复自动化。
- 继续保留r28的简洁大屏、指标修复和后台诊断。当前消耗汇总仍为视频素材，不含直播画面。
- 更新后复用原激活、API授权、账户、飞书、策略及历史数据；完整解压至新目录，退出旧程序后启动新版。不要直接覆盖旧目录。
- Windows程序尚未数字签名，可能显示未知发布者；请核对下载来源和SHA256。
- 本次仅发布GitHub Windows包，不更新自有服务器及其渠道清单。

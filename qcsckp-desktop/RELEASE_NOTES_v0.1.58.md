# 千川素材看盘工具 v0.1.58

Windows x64 官方 API 版稳定性更新。

## 主要更新

- 完善在线激活、一机一码、当前设备自助解绑及原激活码换机流程。
- 修复普通退出激活状态后误清除千川 API 令牌的问题；再次激活可恢复本机监控。
- 千川官方 API 授权按用户本机隔离，App Secret、Token 和飞书凭据使用 Windows DPAPI 加密保存。
- 多账户采集使用持久化队列、同账户受控并发、跨账户公平调度、429 退避与自动恢复。
- 已监控计划每5分钟采集投放中素材及官方报表指标，异常空结果不会覆盖上一轮可信数据。
- 修复大屏账户/计划筛选与素材列表、消耗曲线、ROI曲线、成交金额曲线及汇总图表的联动。
- 首次添加账户改为先快速读取全部计划，仅对用户勾选的计划执行详情核验和指标采集。
- 配置进度只统计已启用账户和已勾选计划，未使用账户不再导致“同步未完成”。
- 移除数据大屏中不完整的调控数据展示界面，后台停投规则与调控任务能力保留。
- 修复 SQLite 历史补录与五分钟热采集之间的写锁饥饿问题。

## 安全与兼容性

- 安装包不包含开发者的激活凭证、App Secret、Token、飞书配置、SQLite 数据库、Cookie、日志或历史投放数据。
- 支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime。
- 本版 Windows 安装包未配置代码签名，首次运行可能出现 SmartScreen 提示。

## 验证

- 完整自动化回归测试：691项通过。
- Windows 发布包在隔离运行目录中执行隐私扫描和启动冒烟测试。

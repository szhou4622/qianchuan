# 千川素材看盘工具 v0.1.64

发布日期：2026-08-26

## 本次更新

- Windows启动改为轻量引导入口；DLL、依赖导入、WebView初始化或窗口创建失败时会写入启动日志并显示原生错误提示，不再无提示退出。
- 公共包启动前校验关键程序文件；安装包不完整或文件被安全软件隔离时会明确指出缺失或校验失败的文件。
- 自动检测 Microsoft Edge WebView2 Runtime；缺失时可由用户确认后运行微软官方签名的 Evergreen 安装组件。
- 增加独立启动故障诊断入口，可输出系统、WebView2、包完整性和最近启动阶段，不包含激活、千川或飞书凭据。
- 规则化追投的素材监控指标固定为整体消耗、净成交金额、净成交ROI、净成交订单数、整体成交金额和整体支付ROI。
- 每条计划根据千川官方报表配置动态判断指标是否可用；不可用指标不能保存为启用策略，也不会按0参与规则判断。
- 数据大屏保留官方缺失值为 `--`，数据库继续保存 `NULL`，避免把“接口未提供”误判为真实0。
- 追投创建请求改为官方字段白名单构造；未知字段、空值、放量/控成本互斥参数及不合法预算、时长、ROI和出价会在POST前拦截。
- 千川返回400154时作为明确参数失败处理，不自动重试，并保留错误码和request_id供排查。

## 更新与本机配置

- 在线更新不删除 `%LOCALAPPDATA%\QCSCKP\official-api-v1`。
- 用户原有激活凭证、千川授权、飞书绑定、监控计划、策略、数据库和历史流水继续使用。
- 旧策略如果使用六项范围以外的素材指标，将停止产生候选，用户需要重新选择支持的指标后保存。
- 公共安装包不包含任何用户激活凭证、App Secret、Token、飞书配置或数据库。

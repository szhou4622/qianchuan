千川素材看盘工具 v0.1.51 官方 API 外部测试版（Windows x64）

一、运行环境
1. Windows 10/11 64 位。
2. 系统需具备 Microsoft Edge WebView2 Runtime（大多数 Windows 10/11 已自带）。
3. 千川官方 API 授权和飞书功能需要联网；工具账号在本机校验，不连接开发者账号服务器。

二、使用方法
1. 请先把整个压缩包解压到一个可写目录，不要在 ZIP 内直接运行。
2. 不要只单独移动 QCSCKP.exe；EXE 与 bin 目录必须保持在同一目录中。
3. 双击 QCSCKP.exe 启动。
4. 首次使用先登录本地工具账号，再在「千川账户管理」填写自己的 App ID、App Secret 并完成官方授权，然后添加千川账户和监控计划。
5. 如需飞书提醒，再完成飞书长连接和接收人的绑定；自动追投模式不强制绑定飞书。
6. 本包不含开发者的千川令牌、数据库、飞书 App Secret、Cookie 或历史业务数据。
7. 本地工具账号由软件提供方单独发送；工具不会访问开发者业务服务器做登录、版本检查或云端备份。

三、数据与日志
1. 运行数据保存在软件目录下的 data 文件夹。
2. 日志保存在 logs 文件夹。
3. 请不要把已使用过的 data 目录发给其他人，其中可能含加密后的登录会话和个人配置。

四、常见问题
1. Windows 首次运行可能显示 SmartScreen 提示；本测试版未配置代码签名证书。
2. 界面无法打开时，请确认 WebView2 Runtime 可用。
3. 千川账户或计划为空时，请先确认官方应用已经授权对应账户及所需权限，再重新授权并刷新账户计划。
4. 出现异常时，请保留 logs 中对应时间的日志供开发者排查，发送前请检查日志中是否含个人信息。
5. 同一个飞书自建应用如果在多台电脑同时连接，请确保所有电脑均升级到 v0.1.50 或更高；新版会按本机实例隔离卡片按钮，避免其他电脑误报“任务不存在”。
6. “每5分钟一轮”表示策略检查频率；是否再次发送提醒还会受到策略中的同素材成功限频约束，两者不是同一个设置。
7. 工具不会写死或读取开放平台中的公网回调地址。每个用户使用自己应用后台已登记的公网 HTTPS 回调；该回调服务必须把原始 auth_code、state 查询参数转交到 http://127.0.0.1:17658/callback。授权必须在运行工具的同一台电脑完成。

五、安全提示
本工具仅可用于你有权操作的千川账户。真实追投或停投前，请再次核对账户、计划、素材、预算、时长和策略。

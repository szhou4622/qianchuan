千川素材看盘工具 v0.1.42 本地独立版（Windows x64）

一、运行环境
1. Windows 10/11 64 位。
2. 电脑需安装 Google Chrome。工具使用本机 Chrome，不内置额外 Chromium。
3. 系统需具备 Microsoft Edge WebView2 Runtime（大多数 Windows 10/11 已自带）。
4. 千川和飞书功能需要联网；工具账号在本机校验，不连接开发者服务器。

二、使用方法
1. 请先把整个压缩包解压到一个可写目录，不要在 ZIP 内直接运行。
2. 不要只单独移动 QCSCKP.exe；EXE 与 bin 目录必须保持在同一目录中。
3. 双击 QCSCKP.exe 启动。
4. 首次使用按页面指引完成本地工具账号、千川 Chrome 登录、千川账户添加、飞书长连接与监控规则配置。
5. 本包不含开发者的 Cookie、数据库、工具账号、飞书 App Secret 或其他凭据。
6. 本地工具账号由软件提供方单独发送；工具不会访问开发者业务服务器做登录、版本检查或云端备份。

三、数据与日志
1. 运行数据保存在软件目录下的 data 文件夹。
2. 日志保存在 logs 文件夹。
3. 请不要把已使用过的 data 目录发给其他人，其中可能含加密后的登录会话和个人配置。

四、常见问题
1. Windows 首次运行可能显示 SmartScreen 提示；本测试版未配置代码签名证书。
2. 界面无法打开时，请确认 WebView2 Runtime 可用。
3. 无法打开千川时，请确认 Google Chrome 已安装到标准路径，或在工具高级设置中选择 chrome.exe。
4. 出现异常时，请保留 logs 中对应时间的日志供开发者排查，发送前请检查日志中是否含个人信息。

五、安全提示
本工具仅可用于你有权操作的千川账户。真实追投或停投前，请再次核对账户、计划、素材、预算、时长和策略。

# 千川素材看盘工具 v0.1.66 开发版 r2：授权连接修复

本次只发布 Windows x64 开发版。正式版和历史稳定版保持不变。

## 更新内容

- 完善激活页“诊断并修复连接”：无需进入主界面即可检查连接，成功后通过原授权重新在线验证，不清除已有激活凭证。
- 支持默认HTTPS、补充内置可信CA和Windows系统HTTPS兼容连接；不关闭证书、域名或吊销校验，不擅自修改系统代理、DNS和防火墙。
- Windows系统HTTPS保留当前明确代理和免代理配置；自动代理脚本无法安全处理时明确提示，不擅自绕过代理。
- 独立修复入口不再触发渠道切换、业务数据复制或错误上报授权弹窗，主界面打不开时也可直接运行。
- 连接错误保留DNS、超时、证书、代理等真实分类；脱敏日志包含HTTP状态、耗时和诊断编号，不包含激活码、Token或设备凭证。
- 保留三渠道隔离和原激活凭证复用；开发版仅检查开发版更新，原正式版和历史稳定版不会自动更新到此测试包。
- 补充证书资源与关键SSL文件的包完整性校验，防止依赖缺失后无法定位启动问题。

## 使用方法

完整解压ZIP，保持 `QCSCKP.exe`、`bin`、`PACKAGE-MANIFEST.json` 在原结构中。
授权连接失败时，在激活页点击“诊断并修复连接”；若主界面打不开，运行同目录的 `QCSCKP-License-Repair.cmd`，完成后重新打开软件。

检测时不携带设备凭证，因此预期的JSON 401表示网络连通，不代表用户的激活码失效，也不代表已经取得软件使用权限。进入软件仍须通过正常的服务器授权校验。

首次从其他渠道切到开发版，按已有切版保护规则备份数据、建立独立业务副本并暂停自动投放。核对账户和平台任务后，再手动恢复策略。此保护不是激活失败。

## 验证与限制

发布前执行授权专项、三渠道隔离和完整自动化回归；构建后验证ZIP、清单、SHA256、隐私扫描及全新用户目录启动。
验证不执行真实千川追投、停投或激活解绑写操作。
本机验证通过不能替代原故障电脑的现场验收；证书域名错误、失效代理、服务器拒绝或真实授权失效不能被自动绕过。

Windows应用暂未数字签名，系统仍可能显示未知发布者提示。安装包不包含开发者的激活凭证、千川/飞书配置或业务数据。

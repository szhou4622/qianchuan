如需继续在分支上开发，应从标签新建分支，不要移动或删除 rc27 标签。

## 回滚本地运行数据

1. 关闭千川工具以及它启动的 Chrome。
2. 备份当前 `desktop-data`。
3. 使用修改前快照中的文件覆盖当前运行目录。
4. 重新启动 rc27 代码。

```powershell
$runtime = 'C:\Users\EDY\AppData\Local\qcsckp-test-runtime\desktop-data'
$snapshot = Join-Path $runtime 'rollback\测试1版-rc27-before-rc28-20260730-204540'
$safety = Join-Path $runtime ('rollback\回滚rc27前保留rc28-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))

New-Item -ItemType Directory -Path $safety | Out-Null
Copy-Item (Join-Path $runtime 'qianchuan.db') $safety
Get-ChildItem $runtime -File -Filter '*.json' | Copy-Item -Destination $safety

Copy-Item (Join-Path $snapshot 'qianchuan.db') $runtime -Force
Get-ChildItem $snapshot -File -Filter '*.json' | Copy-Item -Destination $runtime -Force
```

## rc28 数据变化

- `promotion_target` 新增 `last_verified_at`。
- `promotion_target` 新增 `last_verification_error`。
- `promotion_target` 新增 `write_block_origin`，用于区分人工封锁、核验失败封锁和限频记账失败封锁。
- 旧数据库首次启动 rc28 时会自动新增以上列，不删除历史记录。
- 回滚到 rc27 时应同时恢复 rc27 快照数据库，避免旧程序忽略新增状态字段后产生误判。

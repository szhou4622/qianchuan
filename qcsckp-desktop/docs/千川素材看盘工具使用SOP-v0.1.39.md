# 千川素材看盘工具使用 SOP

适用版本：测试1版 v0.1.39（Windows x64）  
适用场景：同一千川登录身份下，按需添加多个千川账户，监控全域/乘方的推直播、推商品计划，并通过飞书完成追投或停投确认。

## 一、安装和启动

1. 将 Windows 压缩包完整解压到本机文件夹，不要只把 `QCSCKP.exe` 单独拖出来。
2. 确认电脑已安装 Google Chrome，并保持网络正常。
3. 双击 `QCSCKP.exe` 启动工具。首次启动若出现 Windows 安全提示，确认文件来源后选择继续运行。
4. 使用管理员提供的工具账号登录。工具账号用于隔离千川会话、飞书配置、规则和本地任务数据。

注意：不要同时运行多个版本操作同一份数据；软件关闭期间不会采集、追投、停投或接收飞书卡片按钮。

## 二、登录千川并添加账户

1. 进入“千川账户管理”，点击“打开 Chrome 重新登录/核验”。
2. 在弹出的 Google Chrome 中完成千川登录，选择准备添加的千川账户。
3. 进入该账户任意一条计划的详情页。工具确认账户和计划后会保存登录状态并自动关闭本次可见 Chrome。
4. 回到工具，点击“选择并添加当前账户”。工具一次只添加当前选择的账户，不会自动导入登录身份下的全部账户。
5. 如需添加第二个账户，重复以上步骤，在 Chrome 中切换到账户后再添加。
6. 不再使用的账户可从工具中删除。删除后该账户不再参与监控、追投、停投和日报，历史操作流水仍保留。

登录失效、验证码、账户不匹配或授权异常时，工具会暂停全部千川写操作。重新登录后，已经失败的追投任务不会自动补执行，必须由规则重新命中并再次确认。

## 三、同步账户计划目录

1. 添加账户后点击“刷新已添加账户计划”。
2. 等待页面显示排队、扫描中或完成结果，不要连续重复点击。
3. 工具按四类识别计划：
   - 全域 · 推直播
   - 全域 · 推商品
   - 乘方 · 推直播
   - 乘方 · 推商品
4. 工具会展示发现的全部状态计划；暂停、结束、历史、已删除，或场景/体系证据不足的计划不可启用自动化。
5. 若显示“目录不完整”或“待确认”，先重新登录并刷新目录。未通过计划身份和能力核验的计划不会执行追投或停投。

## 四、配置飞书长连接

### 1. 创建飞书应用

在用户自己的飞书企业中创建自建应用，开启机器人能力，并申请以下权限：

- `im:message:send_as_bot`
- `im:message:update`
- `im:message.p2p_msg:readonly`
- `im:message.group_at_msg:readonly`

在“事件与回调”中选择“使用长连接接收事件”，订阅：

- `card.action.trigger`
- `im.message.receive_v1`

完成权限审批后创建并发布应用版本，并确保需要使用的用户和群在应用可用范围内。

### 2. 在工具中连接飞书

1. 进入“飞书绑定”，填写 App ID 和 App Secret 后保存。
2. 启动长连接，确认状态为“已连接”。
3. 个人绑定：生成6位绑定码，在10分钟内私聊机器人发送“绑定 123456”。
4. 群绑定：先把机器人加入群，再由已绑定授权人在群内发送“@机器人 绑定群 123456”。
5. 按需发送测试卡片，确认机器人可以发卡、更新卡片并接收按钮动作。

App Secret 会按工具账号使用 Windows 本机凭据保护加密保存，不上传中心服务器，也不会写入日志。长连接模式不需要服务器、域名、Cloudflare、回调地址、Verification Token 或 Encrypt Key。

## 五、启用账户、接收路由和监控计划

1. 在“千川账户管理”中启用需要自动化的账户。
2. 为该账户选择飞书接收位置：管理员默认位置、已绑定个人、已绑定群，或个人与群同时接收。
3. 如需日报，勾选“同步昨日操作日志并纳入09:00日报”。
4. 在账户右侧计划目录中勾选需要监控的计划。新发现计划默认不启用，工具不会自动操作账户下全部计划。
5. 一次保存账户设置和计划选择，确认页面显示保存成功。

只有“账户已启用 + 飞书已绑定 + 路由已配置 + 计划已勾选 + 计划当前可监控”的组合才会进入采集和规则判断。

## 六、配置规则化追投

1. 进入“规则化追投”，先选择具体监控计划，再新增或编辑策略。
2. 按业务需要选择素材级或商品级触发：
   - 素材级：逐条素材判断。
   - 商品级：仅适用于推商品计划，先汇总商品数据，再按候选条件选择素材。
3. 配置触发条件、预算、时长、目标 ROI/出价、限频和候选素材数量。推商品当前仅支持放量追投；控成本追投仅用于已验证支持的推直播计划。
4. 选择执行方式：
   - 飞书确认后追投：推荐，策略命中后先发30分钟有效卡片。
   - 自动执行：工具复核通过后直接执行。
5. 保存并启用策略。

### 飞书卡片中的素材分组

- 单条：只选一条素材创建一条追投计划。
- 部分或全部合并：把勾选素材作为一组创建一条追投计划。
- 多组追投：同一批命中素材可拆成多组，每组创建一条追投计划。
- 单条分别追投：把多条素材分别作为多条追投计划。
- 素材可按需要重复出现在不同组中；单个追投计划最多20条素材。

点击“确认追投”后，工具会再次核验飞书操作人、账户、计划、商品、素材、策略版本、实时规则、登录状态、限频和页面能力。任一条件不满足都不会提交千川写操作。

## 七、配置规则化停投

1. 进入“规则化停投”，选择需要监控的计划或调控任务并配置条件。
2. 新建策略默认使用“飞书确认后停投”；也可选择“自动执行”。
3. 配置暂停或删除动作、实时指标条件和限频后保存。
4. 飞书卡片会展示账户、计划、全域/乘方、推直播/推商品、调控任务名称和ID、停投动作、规则原因、实时指标与有效期。
5. 点击“确认停投”后，工具会重新检查登录、账户、计划、任务状态、策略版本、实时指标、平台状态和重复流水；校验通过后才执行一次。

## 八、账户操作流水和昨日操作日报

### 账户操作流水

1. 进入“账户操作流水”，先选择千川账户。
2. 设置日期范围，并按操作类型、来源、结果、操作人或关键词筛选。
3. 详情中可查看追投、停投、新建/复制/启停/删除计划，以及预算、出价、ROI修改等投放操作。
4. 点击“导出当前结果”可生成适合中文 Excel 打开的 CSV，导出内容与当前筛选结果一致。

### 昨日操作日报

- 默认每日09:00发送前一日的千川投放操作日志。
- 日报只统计平台投放操作和工具自身执行结果，不把普通浏览器点击轨迹当成操作明细。
- 管理员位置接收全账户总览；有操作记录或同步异常的账户按账户路由发送详情。
- 某账户后台日志覆盖不完整时，卡片会明确显示“同步不完整”，不会虚假标记为完整。

## 九、常见状态说明

- 正常监控：最近一次采集在目标时效内完成。
- 等待监控容量：计划已保存，但当前轮询容量不足，暂不执行自动化。
- 监控延迟：启用后的最近成功采集已超过10分钟；刚启用且尚未完成首轮采集时不应误报延迟。
- 目录不完整：某一分类、分页或详情核验失败，需要重新登录或刷新目录。
- 需要重新登录：Cookie、授权或验证码状态异常，全部千川写操作已暂停。
- 飞书断线：工具暂时无法接收卡片按钮；恢复连接后，在卡片有效期内重新点击。

## 十、故障处理

1. 千川显示未登录：点击“打开 Chrome 重新登录/核验”，完成登录并进入计划详情。
2. 刷新计划无结果：查看刷新状态和故障诊断，确认账户仍有访问权限后重试。
3. 计划显示待确认：打开该计划详情完成核验，再刷新已添加账户计划。
4. 飞书卡片按钮报错：确认应用已发布、长连接已连接、事件已订阅、点击人是绑定授权人，然后重新发送测试卡片。
5. 追投或停投失败：先看卡片失败原因和账户操作流水；不要反复点击，修复登录、策略或能力问题后等待重新命中。
6. 日报缺数据：查看对应账户的后台日志覆盖时间和同步状态；同步不完整时先恢复千川登录和日志权限。

## 十一、安全边界

- 工具只操作用户已添加的账户和明确勾选的计划。
- 追投、停投执行期间使用全局独占浏览器队列，避免跨账户页面互相覆盖。
- 登录失效、验证码、账户不匹配、计划不匹配、素材变化或能力证据不足时一律安全停止。
- 不把千川 Cookie、飞书 App Secret、工具账号密码写入文档、Git、日志或操作流水。
- 真实投放前先使用受控账户、指定计划、指定素材和受控预算完成验收。

## 二、功能生命周期（端到端字符流程）

下列流程覆盖「从启动到看盘、可选外发」的**完整闭环**。

```
  [1] 启动应用
        │
        ▼
  ┌─────────────────┐
  │ gui_app 初始化   │──► 清理 data/temp（可选）
  │ 单实例检查       │──► 若已运行：写 command.json，新进程退出
  │ 托盘 / 窗口尺寸  │
  │ SQLite 裁剪线程  │──► 后台按配置裁剪历史行数
  │ Webhook 推送线程 │──► 整点任务（读配置，未启用则跳过）
  └────────┬────────┘
           │
           ▼
  [2] 用户在大屏界面操作
        │
        ├──► 远程登录校验（账号+密码）─────────► AccountAuthApi ──► API_BASE_URL
        │
        ▼
  [3] 用户点击「启动采集」
        │
        ├──► 再次服务端校验「是否允许启动」────► AccountAuthApi
        │         │
        │         └── 未通过 ──► 不启动 ServiceController 线程，界面提示
        │
        ▼
  [4] ServiceController.start()
        │
        ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ [4a] 有头浏览器打开千川登录页                                   │
  │ [4b] 用户手动登录（人工在浏览器内完成）                         │
  │ [4c] 轮询当前页 URL，直到匹配「详情页前缀」且解析出 aavid + adId │
  │ [4d] 按工具账号使用Windows DPAPI加密保存一份千川主登录会话       │
  │ [4e] 关闭浏览器，按用户选项以有头/无头重启，并 goto 构造好的抓取 URL │
  └────────────────────────────┬────────────────────────────────┘
                               │
                               ▼
  [5] 轮询循环（直到用户停止）
        │
        ├──► 按间隔（≥5s，可界面修改，下轮生效）触发一轮 fetch
        │
        ├──► Playwright 页面内触发/等待素材列表 API
        │
        ├──► 拦截响应 → clean_pmc_promotion_data → 写入 SQLite
        │
        ├──► 每轮结束可再次 storage_state 刷新 Cookie
        │
        ├──► 若配置了飞书多维表 token：本轮入库后同步 Base（快照在轮询开始时读取）
        │
        └──► 状态/进度回写到 ServiceController，供 getServiceStatus 轮询
                               │
                               ▼
  [6] 看盘只读路径（与采集并行）
        │
        └──► DashboardApi 读 SQLite
                  │
                  ├──► 表格分页、周期筛选、排序
                  ├──► 素材历史折线（当日数据等规则）
                  ├──► Top 消耗、汇总类接口
                  │
                  └──► 前端 ECharts 等渲染 static/dashboard.html / index.html
                               │
                               ▼
  [7] 可选：飞书 Webhook 整点推送
        │
        └──► 读取 data 下 Webhook 配置 → 调用 hook 封装 → 推送到群机器人
                               │
                               ▼
  [8] 用户关闭窗口 / 托盘退出 / 停止服务
        │
        ├──► stopService → 抓取线程收尾、关闭浏览器
        └──► 进程退出；SQLite 与日志保留在本地
```

## 三、生命周期阶段与模块对照表

| 阶段 | 用户感知 | 主要代码入口 |
|------|----------|----------------|
| 启动壳 | 出现窗口、托盘 | `gui_app.py` |
| 账号 | 登录失败/成功 | `api/account_auth.py` |
| 启停采集 | 浏览器、进度文案 | `services/run_services.py` → `QianChuanFetcher` |
| 数据落库 | 表格变新 | `utils/sqlite_store.py`、`services/fetcher.py` |
| 大屏 | 图表与列表 | `api/dashboard.py`、`static/` |
| 外发 | 飞书表 / 群消息 | `services/feishu_bitable/`、`services/feishu_webhook_push.py`、`hook/` |
| 维护 | 库体积可控 | `utils/sqlite_prune_scheduler.py`、`config` 中裁剪参数 |

## 回滚基线

- rc27 开发基线：`测试1版-rc26`
- rc27 版本号：`v0.1.30`
- 修改前运行数据快照：
  `C:\Users\EDY\AppData\Local\qcsckp-test-runtime\desktop-data\rollback\测试1版-rc26-before-rc27-20260730-154934`
- 快照包含：SQLite 数据库、千川登录会话、飞书本地配置、规则配置和本地服务配置。

## 只回滚代码

先完全退出千川素材看盘工具，再在仓库目录执行：

```powershell
git switch -c 测试1版-rc26-回滚 测试1版-rc26
```

该命令会从 rc26 标签创建独立回滚分支，不改写 `测试1版` 分支历史。

## 同时回滚本地数据

1. 从托盘菜单完全退出工具，确认测试桌面进程已经停止。
2. 先备份当前 `desktop-data`，避免覆盖 rc27 运行数据后无法恢复。
3. 在 PowerShell 执行：

```powershell
$runtime = Join-Path $env:LOCALAPPDATA 'qcsckp-test-runtime\desktop-data'
$snapshot = Join-Path $runtime 'rollback\测试1版-rc26-before-rc27-20260730-154934'
$safety = Join-Path $runtime ('rollback\回滚rc26前保留rc27-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $safety -Force | Out-Null
Get-ChildItem -LiteralPath $runtime -File | ForEach-Object {
    Copy-Item -LiteralPath $_.FullName -Destination $safety -Force
}
Get-ChildItem -LiteralPath $snapshot -File | ForEach-Object {
    Copy-Item -LiteralPath $_.FullName -Destination $runtime -Force
}
```

4. 从 `测试1版-rc26-回滚` 分支重新启动测试桌面端。

## 回滚校验

- 窗口版本应恢复为 rc26 对应版本。
- 千川和飞书凭据只从本机快照恢复，不从 Git 获取。
- 打开账户管理、飞书绑定、规则化追投和规则化停投页面，确认原有配置可读取。
- 不要使用真实追投开关做回滚验证；先保持 `QCSCKP_ALLOW_LIVE_RETARGET=0` 完成只读检查。

# 千川素材看盘工具 v0.1.66 正式版 r30

Windows x64，基于r29，修复追投核验并完善结果、采集恢复与停投诊断。

- 修复直播控成本未设置时长被空字符串错误核验的问题；新核验参数保存null及实际创建参数，放量时长继续严格核对。
- 仅有可信创建证据、明确已接受且已有调控ID的历史空时长误判，自动按原ID只读复核一次，最多8次有限查询；不重新创建追投。
- 追投流水区分提交核验中、结果待核对和确认成功。原卡更新记录业务版本、内容摘要及消息回执；无回执不宣称送达，迟到队列重新读取最新业务状态。
- 提交前素材分页使用最多3页并发，共享300秒预检预算及一次完整重扫上限；仍不稳定时说明未提交，不取消归属、分页、授权和领取检查。
- 保留98%系统提交内存/512MB余量资源保护；账户页显示资源等待，悬停说明资源情况。恢复后先完成串行实时采集，再恢复原有调度，不让历史补采抢先。
- 本地记录有限的采集调度、资源等待、停投指标判断与跳过原因，故障报告导出关联证据及卡片更新摘要；不新增服务器上报。
- 目录、采集和停投扫描保持300秒；不改策略、预算、时长或主计划，不增加直播画面采集。

## 更新与使用

- 完整解压到新目录，退出旧程序后启动r30；继续复用本机激活、千川授权、飞书绑定、账户、策略和历史数据，不要覆盖旧目录。
- 历史自动复核只处理有证据的直播控成本空时长误判，不代表所有失败/未知任务都会恢复，也不会重新创建调控任务。其他电脑需安装本版后才生效。
- 5分钟是正常调度周期，限流、队列或系统提交内存压力仍可能延长成功采集间隔；不会为了恢复采集而取消资源保护。
- 当前消耗汇总仍为视频素材，不包含直播画面；未调整这一统计范围。
- Windows程序尚未数字签名，可能提示未知发布者；请核对下载来源和SHA256。
- 本次只发布GitHub Windows包，不同步自有服务器及其更新清单，保留旧版本。

# v0.1.66 r22 本地指标核对版

本地验证用途。学员的真实全零原因尚需新一轮原始指标样本确认；不能仅凭升级后能启动就视为经营数据已恢复。

- 素材接口的原生数值不再套用账户报表的单位换算；缺失、无效和非有限数值保持为空，合法零值仍保留为零。
- 大屏区分指标缺失、全零待核对和数据新鲜。汇总不把全部空值显示为0，部分缺失时说明仅合计有效值；曲线对缺失数据保留断点。
- 原则上继续使用单计划素材指标，不用账户级报表覆盖主计划素材快照。
- 修正版首次采集建立指标比较基准，流速和当日曲线避免混用旧单位快照；原历史记录保留。
- 每轮保存至多6条素材的数值类型、原始数值、解析数值、单位背景和请求编号。导出报告前置指标摘要，并关联实际入库值与后端数字转换值；明确这不是浏览器画面的现场捕获。
- 报告可直接说明“原始全零”“字段缺失/解析异常”“旧版本未记录指标证据”，并标记样本是否属于同一轮，防止误判。

验证时请在同一账户、同一计划、同一天选一条后台有明确消耗的素材，与报告中的同一素材核对。若素材接口实际返回0，该版不会编造或借用其他计划的数值。

本轮不更新GitHub或服务器正式清单，不改动预算、时长或投放策略。

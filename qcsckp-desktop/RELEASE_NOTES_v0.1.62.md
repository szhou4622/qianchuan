# 千川素材看盘工具 v0.1.62

发布日期：2026-08-26

## 本次更新

- 将乘方推直播控成本追投的用户可见指标名统一修正为“综合营销ROI”，保留旧配置兼容和已验证的官方API字段。
- 规则化停投的前端、飞书卡片和结果通知统一使用“暂停调控／结束调控”；结束操作映射官方API的 `DISABLE`，不调用删除接口。
- 自动停投被千川API受理后立即发送“已提交，正在核验”飞书卡片，后台核验完成后继续发送成功、失败或无法确认的最终结果。
- 修复自动停投进入后台对账后没有本地确认卡片、导致最终结果未通知用户的问题。
- 飞书长连接重连期间，停投结果通知仍可通过REST发送；临时发送失败会进入本地发件箱重试。
- 停投遇到平台429限频时遵循平台等待时间，最多尝试3次；参数、权限、任务状态等明确失败只提交1次。
- POST超时、断网或5xxxx等无法确认的停投结果不会重复提交，只通过只读查询核验平台最终状态。

## 更新与本机配置

- 在线更新不删除 `%LOCALAPPDATA%\QCSCKP\official-api-v1`。
- 用户原有激活凭证、千川授权、飞书绑定、监控计划、策略、数据库和历史流水继续使用。
- 公共安装包不包含任何用户激活凭证、App Secret、Token、飞书配置或数据库。

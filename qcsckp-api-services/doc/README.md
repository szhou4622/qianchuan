# doc · 开发文档

本目录收录**桌面端**对接用的 API 说明（Markdown 源文件）。

## 阅读方式

1. **浏览器（推荐）**：部署后访问 **`/doc/`** 或 **`/doc/index.html`**，左侧切换文档，正文为渲染后的 HTML。
2. **本地/IDE**：直接打开同目录下的 `*.md` 文件编辑或预览。
